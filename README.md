# WASD 2D Weapon Pool

This package contains a normalized 270-weapon atlas for the Pixi 2D client.

Copy the `apps/` folder into the repository root.

Target files:
- `apps/client-2d/public/2d-assets/weapons/weapon-atlas.png`
- `apps/client-2d/public/2d-assets/weapons/weapon-manifest.json`
- `apps/client-2d/public/2d-assets/credits/weapon-packs.md`

The current code PR adds `weapons` schema support and a deterministic `pickWeaponVisual(...)` helper.
