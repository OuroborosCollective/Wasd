# Pipoya 2D asset packs

Integrated from ZIP files uploaded by the repository owner in ChatGPT on 2026-05-19.

Source packs used for this active starter subset:

- Pipoya RPG World Tileset 48x48 40x40 32x32.zip
- Pipoya RPG Monster Pack.zip
- PIPOYA FREE RPG Character Sprites 32x32.zip
- Door_Animation.zip
- Pipoya RPG Tileset 32x32.zip

The current `/2d-assets/manifest.json` stores a small active starter subset as embedded PNG data URIs so the Pixi 2D client can render real 2D assets immediately after deploy.

A later full-pack import can still extract the complete ZIP contents into category folders and regenerate the manifest.

Do not replace these with copyrighted Ragnarok Online original assets.
