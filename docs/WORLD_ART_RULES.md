# World art rules

Use only clear world art for map placement.

## Allowed

- terrain
- props
- decoration
- NPCs
- items
- weapons

## Not allowed for map placement

- UI pieces
- letters
- labels
- symbols
- temporary images

## Metadata

Each art entry should have a stable id, type, path, tags, and fallback.

## Review rule

When an image is unclear, keep it out of the map until it is classified.
