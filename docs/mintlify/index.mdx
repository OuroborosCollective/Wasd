# Areloria WASD

**Areloria WASD** is a browser-native deterministic MMORPG engine and living-world simulation platform built with Node.js, WebSockets, and PixiJS/Babylon.js rendering clients.

![License](https://img.shields.io/badge/runtime-deterministic_10Hz-blue)
![Client](https://img.shields.io/badge/client-2D_first-cyan)
![Simulation](https://img.shields.io/badge/simulation-ARE_logic-purple)

## What is Areloria?

Areloria is not designed as a simple web game shell. It is an attempt to build a mathematically disciplined, **deterministic living-world engine** for a browser MMORPG.

<Card title="Server Authority" icon="server" href="/docs/mintlify/architecture/server">
  All game state is validated and mutated authoritatively on the server. Clients render what the server confirms.
</Card>

<Card title="Deterministic Simulation" icon="hash" href="/docs/mintlify/architecture/determinism">
  Every gameplay outcome is reproducible from explicit inputs. No hidden randomness, no client authority.
</Card>

<Card title="Living NPCs" icon="users" href="/docs/mintlify/gameplay/npc-systems">
  NPCs remember local events, react to player history, and participate in emergent civilization systems.
</Card>

<Card title="2D & 3D Clients" icon="monitor" href="/docs/mintlify/architecture/client">
  Primary 2D rendering via PixiJS v7 + React. 3D rendering via Babylon.js when needed.
</Card>

## Core Truth Rule

Every feature in Areloria follows this fundamental rule:

```text
Kein Snapshot, kein Spiel.
Kein Tick, keine Wahrheit.
Kein Guard, keine Architektur.
Kein /2d Proof, keine Integration.
```

A feature is considered real only when it is visible or verifiable through the active runtime path, server state, generated manifest, replay/state hash, or CI/smoke test.

## Architecture Highlights

| Component | Technology | Purpose |
|-----------|------------|---------|
| Game Server | Node.js + Express + WebSocket | Authoritative 10Hz simulation |
| 2D Client | PixiJS v7 + React | Primary rendering surface |
| 3D Client | Babylon.js + Vite | Extended visualization |
| Persistence | PostgreSQL / JSON fallback | Player & world state |
| Assets | Stitch 2.5D sprite atlas | Visual content pipeline |

## Vision

The world should feel **inhabited** rather than merely scripted. NPCs are future citizens, workers, traders, witnesses, political actors, enemies, allies, informants, settlers, rulers, rebels, and memory-bearing participants in a simulated civilization.

Long-term targets:
- NPCs remember local events and react to player history
- Villages, towns, cities, kingdoms emerge from deterministic rules
- Trade routes, taxes, elections, wars become systemic forces
- Oracle/prophecy systems observe patterns and expose world-thought to players
