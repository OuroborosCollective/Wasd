# Quickstart

Begin your journey with Areloria WASD. This guide takes you from zero to a running game server with 2D client.

## Prerequisites

Before you begin, ensure you have:

- **Node.js 22.x** or higher
- **pnpm 9+** (or npm/yarn with pnpm compatibility)
- **Python 3.x** with Pillow (for asset pipeline)
- **Docker** (optional, for production-style testing)
- **Git** for version control

## Installation

### 1. Clone the Repository

```bash
git clone https://github.com/OuroborosCollective/Areloria-WASD.git
cd Areloria-WASD
```

### 2. Install Dependencies

```bash
pnpm install
```

### 3. Build the Shared Package

The `@wasd/shared` package must be built before the client works:

```bash
pnpm -C packages/shared build
```

If you encounter import resolution errors, clear the build cache:

```bash
rm packages/shared/*.tsbuildinfo
pnpm -C packages/shared build
```

## Running the Development Server

### Option 1: Full Monorepo Build (Recommended)

```bash
pnpm build
```

This builds clients first, then the server with embedded Vite middleware.

### Option 2: Server Only

```bash
npx tsx server/src/index.ts
```

The server runs on **port 3000** with embedded Vite middleware for development.

### Option 3: Separate Server and Client

Terminal 1 - Game Server:
```bash
pnpm --filter @wasd/server dev
```

Terminal 2 - 2D Client:
```bash
pnpm --filter @wasd/client-2d dev
```

## Verify the Server

Once running, check the health endpoint:

```bash
curl http://localhost:3000/health
```

Expected response:
```json
{
  "status": "ok",
  "auth": "stub",
  "persistence": "file",
  "content": "game-data",
  "playtester": "disabled"
}
```

## Access the Client

Navigate to:
- **2D Client**: http://localhost:3000/2d
- **Admin Panel**: http://localhost:3000/admin-content.html
- **Health Check**: http://localhost:3000/health

## Common Commands

| Command | Description |
|---------|-------------|
| `pnpm install` | Install all dependencies |
| `pnpm build` | Build entire monorepo |
| `pnpm build:2d` | Build 2D client only |
| `pnpm build:server` | Build server only |
| `pnpm dev:2d` | Run 2D client dev server |
| `pnpm lint` | Run ESLint |
| `pnpm test` | Run unit/integration tests |
| `pnpm test:e2e` | Run end-to-end tests |

## Environment Variables

Create a `.env` file based on the template:

```bash
cp .env.example .env
```

Key variables:

| Variable | Default | Description |
|----------|---------|-------------|
| `PORT` | `3000` | Server port |
| `PERSISTENCE_DRIVER` | `auto` | Persistence: auto, postgres, file |
| `AUTH_PROVIDER` | `none` | Auth: supabase, none |
| `NODE_ENV` | `development` | Environment mode |

## Troubleshooting

### "Failed to resolve import @wasd/shared"

Rebuild the shared package:
```bash
rm packages/shared/*.tsbuildinfo
pnpm -C packages/shared build
```

### WebSocket connection issues

Check that the server is running and the port is not blocked by a firewall.

### Client shows blank page

Ensure Vite middleware is running. Try:
```bash
pnpm build:2d
```
