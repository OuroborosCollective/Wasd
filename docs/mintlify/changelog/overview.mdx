<Update label="June 25, 2026" description="NPC dialogue shortcuts and accessibility">

This week's release makes NPC conversations faster to navigate from the keyboard and clearer for assistive tech.

## Updates

- **Numeric shortcuts in NPC dialogue.** Each option in an NPC interaction menu is now bound to its on-screen number key (`1`, `2`, `3`, …). Pressing the key selects and confirms that option in one step, so common NPC actions like trade, talk, or quest hand-in no longer require arrow keys plus `Enter`. Disabled options ignore their shortcut. Press `0` or `Escape` to leave the menu. See [NPC systems](/mintlify/gameplay/npc-systems).
- **`ESC` hint on the NPC dialogue close button.** The NPC context window's close button now shows a visible `ESC` label and exposes an `aria-label` and `aria-keyshortcuts` so screen readers announce the shortcut. The button keeps the same hit area and styling as the standardized gameplay window close buttons. See [Client architecture](/mintlify/architecture/client).

</Update>

<Update label="June 25, 2026" description="Standardized gameplay window close buttons">

This week's release adds a consistent close control to every gameplay HUD window.

## Updates

- **Close buttons on all gameplay windows.** Character, Quest Journal, Skills, and the rest of the gameplay panels now share a standardized close button in the window header. Each button shows a visible `ESC` keyboard hint and exposes accessibility labels. Closing a window dismisses it the same way as toggling the panel from the HUD. See [Client architecture](/mintlify/architecture/client).

</Update>

<Update label="June 25, 2026" description="HUD bridge for the 2D client">

This week's release wires the in-world HUD onto the 2D renderer so vitals, chunk position, and chat sit on top of the live world instead of in a separate preview.

## New features

- **HUD bridge for the 2D client.** The 2D renderer now mounts the Arelorian Stitch HUD on top of the live world. While you play, the HUD surfaces player vitals (HP, mana, stamina, XP, level), current chunk coordinates, visible chunk count, and a rolling chat log. Skill, interact, strike, weapon cycle, and chat inputs route through the HUD into the world view. See [Client architecture](/mintlify/architecture/client).

</Update>

<Update label="June 24, 2026" description="2D world renderer fixes">

This week's release upgrades the 2D client renderer so the world streams in cleanly and NPCs visibly move around it, with follow-up hardening for visual consistency.

## Fixes

- **2D world renderer now streams chunks and animates NPCs.** The 2D client switches to the newer renderer path, which streams world chunks as you move and shows NPC motion in real time instead of stalling on a static scene. The scene renderer also handles texture atlas edge cases safely, removing a class of missing-tile glitches. See [Client architecture](/mintlify/architecture/client).
- **Deterministic visual asset ordering.** The 2D client now picks visual assets in a stable order and filters out known letter, number, sheet, and font artifacts before they can bind to world objects. Two players in the same scene see the same sprites, and a class of stray glyph-on-tile glitches is gone. See [Determinism](/mintlify/architecture/determinism).

</Update>

<Update label="June 23, 2026" description="Camp quests, runtime truth, and determinism hardening">

This week's release closes out the camp daily quest loop, hardens the live gameplay snapshot against placeholder data, and tightens determinism across the engine.

## New features

- **Server-authoritative camp quest delivery.** Players can now hand in camp daily quests through a dedicated completion endpoint. The server validates requirements and rewards, drops completed offers from the live snapshot, and applies inventory deltas deterministically. See [Quest system](/mintlify/gameplay/quest-system).
- **Deterministic camp daily quest offers.** Each discovered camp now generates a stable daily quest offer from world seed and tick. Two players exploring the same camp see the same objectives, and offers appear in the live gameplay snapshot as soon as a camp is discovered. See [NPC systems](/mintlify/gameplay/npc-systems).
- **Resource expansion quest pack.** A new additive quest set loads through the quest engine and expands the gathering and processing progression beyond the starter loop. See [Quest system](/mintlify/gameplay/quest-system).
- **Runtime validation across ARE-Logic and data flow.** A new validation layer continuously checks combat, inventory, chunk, and tick subsystems at runtime and surfaces drift early. See [Determinism](/mintlify/architecture/determinism).

## Updates

- **Runtime truth for guild, faction, and NPC activity.** The live gameplay snapshot now pulls guild, faction, and NPC activity from runtime providers instead of placeholder paths, so the client renders authoritative server state. See [Truth path](/mintlify/architecture/truth-path).
- **Combat tick processing is now operational.** Combat resolves on every tick instead of relying on partial updates, which clears a class of stuck engagements.
- **Loot quarantine for missing base items.** The loot system now quarantines and logs drops that reference unknown base items instead of fabricating them, which prevents phantom rewards from entering inventories. See [Economy](/mintlify/gameplay/economy).
- **Faster quest sync.** The quest engine reconciles progress against inventory in a single pass, cutting per-tick cost on characters with large inventories.
- **Faster NPC delta snapshots.** Population change detection now compares NPCs by properties instead of serializing the full population, cutting snapshot work on busy regions.

## Fixes

- **Stateless determinism audit cleanup.** Client request IDs, guest player IDs, input timestamps, chunk and render biomes, and ARE state commit IDs now derive from tick and seed instead of wall-clock or volatile sources. Replays and reconnects stay byte-identical. See [Determinism](/mintlify/architecture/determinism).
- **Deterministic asset binding fallbacks.** The 2D client now picks fallback asset IDs from a deterministic source, which removes a subtle visual drift between sessions.
- **Admin and auth route hardening.** Asset pipeline and admin endpoints are now properly typed and rate-limited, closing gaps the server type checker surfaced. See [REST API](/mintlify/api/rest).

</Update>
