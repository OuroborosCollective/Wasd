<Update label="June 23, 2026" description="Camp quests, runtime truth, and determinism hardening">

This week's release focuses on closing out the camp daily quest loop end-to-end, hardening the live gameplay snapshot against placeholder data, and tightening determinism across the engine.

## New features

- **Server-authoritative camp quest delivery.** Players can now hand in camp daily quests through a dedicated completion endpoint. Requirements and rewards are validated server-side, completed offers are removed from the live snapshot, and inventory deltas land deterministically. See [Quest system](/mintlify/gameplay/quest-system).
- **Deterministic camp daily quest offers.** Each discovered camp now generates a stable daily quest offer driven by world seed and tick, so two players exploring the same camp see the same objectives. Offers appear in the live gameplay snapshot once a camp is discovered. See [NPC systems](/mintlify/gameplay/npc-systems).
- **Resource expansion quest pack.** A new additive quest set loads through the quest engine, expanding the gathering and processing progression beyond the starter loop. See [Quest system](/mintlify/gameplay/quest-system).
- **Runtime validation across ARE-Logic and data flow.** A new validation layer continuously checks combat, inventory, chunk, and tick subsystems at runtime and surfaces drift early. See [Determinism](/mintlify/architecture/determinism).

## Updates

- **Runtime truth for guild, faction, and NPC activity.** The live gameplay snapshot now sources guild, faction, and NPC activity from runtime providers instead of placeholder paths, so what the client renders matches authoritative server state. See [Truth path](/mintlify/architecture/truth-path).
- **Combat tick processing is now operational.** Combat resolves on every tick rather than relying on partial updates, removing a class of "stuck" engagements.
- **Loot quarantine for missing base items.** Drops that reference unknown base items are now quarantined and logged instead of fabricated, preventing phantom rewards from entering inventories. See [Economy](/mintlify/gameplay/economy).
- **Faster quest sync.** Quest progress reconciles against inventory in a single pass, reducing per-tick cost on characters with large inventories.
- **Faster NPC delta snapshots.** Population change detection now compares NPCs by properties instead of serializing the full population, cutting snapshot work on busy regions.

## Fixes

- **Stateless determinism audit cleanup.** Client request IDs, guest player IDs, input timestamps, chunk biomes, render biomes, and ARE state commit IDs are now derived from tick and seed instead of wall-clock or volatile sources, so replays and reconnects stay byte-identical. See [Determinism](/mintlify/architecture/determinism).
- **Deterministic asset binding fallbacks.** The 2D client now picks fallback asset IDs from a deterministic source, removing a subtle visual drift between sessions.
- **Admin and auth route hardening.** Asset pipeline and admin endpoints are now properly typed and rate-limited, closing gaps surfaced by the server type checker. See [REST API](/mintlify/api/rest).

</Update>
