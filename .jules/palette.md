## 2026-06-15 - Enhancing Keyboard Accessibility on Overlay Dialogues
**Learning:** Game dialogue overlays that use basic un-styled elements or non-brutalist rounding can feel out of place. Upgrading them to use sharp borders (`borderRadius: "0px"`) matches the CyberZen Diamond Glass design system, while equipping close buttons with stateful hover effects, accessible ARIA keyshortcuts, and visible keyboard shortcuts (`<kbd>ESC</kbd>`) significantly eases keyboard-only gameplay.
**Action:** Always pair in-game modal dialogues and overlays with visible keyboard shortcut helpers and complete accessibility attributes (such as `aria-keyshortcuts="Escape"`).
